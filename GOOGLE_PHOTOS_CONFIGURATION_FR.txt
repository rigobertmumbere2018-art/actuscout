ACTUSCOUT — GOOGLE PHOTOS PICKER ET CLOUDFLARE R2

INTÉGRATION
- Connexion OAuth Google depuis l'administration.
- Sélection explicite des photos/vidéos via Google Photos Picker.
- Import des fichiers sélectionnés dans le bucket R2 actuscout-galeries.
- Enregistrement des URLs et métadonnées dans D1 et association à l'album choisi.
- Jeton de renouvellement Google chiffré en AES-GCM dans D1.

CONFIGURATION CLOUDFLARE
Worker : actuscout
URL : https://actuscout.rigobertmumbere2018.workers.dev

Liaisons déjà déclarées dans wrangler.toml :
- D1 : actuscout-db (binding DB)
- R2 : actuscout-galeries (binding GALLERY)

Variable du Worker :
R2_PUBLIC_BASE = https://pub-e89d0ce066dcb4b32a5acdfc6e80af4cb.r2.dev

Secrets à configurer dans les paramètres du Worker :
- GOOGLE_CLIENT_ID
- GOOGLE_CLIENT_SECRET
- GOOGLE_TOKEN_ENCRYPTION_KEY (valeur aléatoire longue, au moins 32 caractères)

CONFIGURATION GOOGLE CLOUD
1. Dans Google Cloud Console, sélectionner le projet utilisé par ActuScout.
2. Activer Google Photos Picker API.
3. Configurer l'écran de consentement OAuth et ajouter le compte administrateur comme utilisateur test si l'application est en mode test.
4. Créer un identifiant OAuth Client ID de type Application Web.
5. Origine JavaScript autorisée :
   https://actuscout.rigobertmumbere2018.workers.dev
6. URI de redirection autorisée :
   https://actuscout.rigobertmumbere2018.workers.dev/api/google/callback
7. Enregistrer le Client ID et le Client secret dans les secrets du Worker.
8. Scope utilisé :
   https://www.googleapis.com/auth/photospicker.mediaitems.readonly\n   https://www.googleapis.com/auth/drive.readonly

UTILISATION
1. Se connecter à /admin.
2. Cliquer sur « Connecter Google Photos » et autoriser le compte.
3. Choisir l'album de destination.
4. Lancer « Importer la sélection terminée » pour ouvrir la sélection Google Photos.
5. Sélectionner les médias et terminer la sélection dans Google Photos.
6. Revenir dans l'administration et relancer l'action pour transférer les fichiers vers R2.

À SAVOIR
- Google Photos Picker donne accès uniquement aux médias sélectionnés explicitement.
- Les URL baseUrl de Google sont temporaires ; le Worker doit télécharger les fichiers et les copier dans R2.
- Le bucket doit autoriser la lecture publique des objets pour afficher les images sur le site.
- Le domaine r2.dev convient aux essais ; pour la production, envisager un domaine personnalisé R2.
- Ne pas supprimer les ressources existantes de D1 ou R2 pendant les mises à jour.
