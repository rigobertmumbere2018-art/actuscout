ACTUSCOUT — INTÉGRATION GOOGLE PHOTOS PICKER + CLOUDFLARE R2

CE QUI EST PRÉVU
- Connexion OAuth Google depuis l'administration.
- Sélection explicite des photos/vidéos via Google Photos Picker (jamais d'accès global à la photothèque).
- Import des fichiers sélectionnés dans le bucket R2 actuscout-galeries.
- Enregistrement des URLs et métadonnées dans D1, association à l'album choisi.
- Jeton de renouvellement Google chiffré en AES-GCM dans D1.

PRÉREQUIS CLOUDFLARE
1. Worker bold-pine-89ed : conserver la liaison D1 DB et ajouter la liaison R2 : variable GALLERY, bucket actuscout-galeries.
2. Dans les variables du Worker, ajouter R2_PUBLIC_BASE = https://pub-e89d0ce066dcb4b32a5acdfc6e80af4cb.r2.dev
3. Ajouter ces SECRETS (jamais les publier dans le code) :
   GOOGLE_CLIENT_ID
   GOOGLE_CLIENT_SECRET
   GOOGLE_TOKEN_ENCRYPTION_KEY (une phrase secrète longue et aléatoire, au moins 32 caractères)
4. Appliquer les migrations D1 : npx wrangler d1 migrations apply actuscout-db --remote

CONFIGURATION GOOGLE CLOUD
1. Dans Google Cloud Console, créer/sélectionner un projet.
2. Activer Google Photos Picker API.
3. Configurer l'écran de consentement OAuth. Pour les tests, ajouter le compte Google administrateur comme utilisateur test. Pour une utilisation publique, préparer la vérification OAuth Google selon les exigences applicables.
4. Créer un identifiant OAuth Client ID de type Application Web.
5. Origine JavaScript autorisée : https://bold-pine-89ed.rigobertmumbere2018.workers.dev
6. URI de redirection autorisée : https://bold-pine-89ed.rigobertmumbere2018.workers.dev/api/google/callback
7. Copier le Client ID et le Client secret dans les secrets du Worker.
8. Scope demandé par l'application : https://www.googleapis.com/auth/photospicker.mediaitems.readonly

FLUX D'UTILISATION
1. Se connecter à /admin.
2. Cliquer « Connecter Google Photos » et autoriser le compte voulu.
3. Choisir l'album de destination.
4. Cliquer « Importer la sélection terminée » : une fenêtre Google s'ouvre.
5. Sélectionner les photos et terminer la sélection dans Google Photos.
6. Revenir dans l'administration et cliquer de nouveau « Importer la sélection terminée » pour transférer les fichiers vers R2.

IMPORTANT
- Google Photos Picker ne donne accès qu'aux médias explicitement choisis par l'utilisateur.
- Les baseUrl Google sont temporaires (environ 60 minutes) : le Worker télécharge immédiatement les fichiers et les copie dans R2.
- Le bucket doit avoir un accès public lecture correctement configuré pour afficher les URL des photos sur le site. Le domaine r2.dev est destiné au développement/essais et a des limites; pour la production, utiliser un domaine personnalisé R2.
- Les secrets OAuth et de chiffrement doivent être configurés avant le premier essai.
- Après déploiement, vérifier les réponses et l'affichage des images sur le site public. Le endpoint public /api/public/albums inclut désormais le tableau photos.
