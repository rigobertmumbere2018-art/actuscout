ACTUSCOUT — DÉPLOIEMENT DU WORKER EXISTANT
===========================================

Worker de production : actuscout
URL : https://actuscout.rigobertmumbere2018.workers.dev
Base D1 : actuscout-db
Bucket R2 : actuscout-galeries

Le fichier wrangler.toml est déjà renseigné avec les liaisons D1 et R2 existantes.
Ne recrée pas la base D1 ni le bucket R2. Ne supprime aucun album, article ou fichier
déjà enregistré.

CONTENU DU PROJET
- Site public ActuScout et ses ressources visuelles existantes
- API des articles et albums publiés
- Administration /admin avec authentification
- Gestion des articles et albums
- Import de médias Google Photos Picker vers R2\n- Candidatures blogueurs, CV PDF, validation administrative et espace de soumission d’articles\n- Page de soutien / dons (coordonnées de paiement à compléter)
- Stockage des métadonnées de galerie dans D1

DÉPLOIEMENT
1. Installer Node.js LTS : https://nodejs.org/
2. Ouvrir un terminal dans le dossier du projet.
3. Installer les dépendances si le projet en possède : npm install
4. Se connecter à Cloudflare si nécessaire : npx wrangler login
5. Vérifier le fichier wrangler.toml et les liaisons existantes.
6. Déployer : npx wrangler deploy

SECRETS DU WORKER
Configurer dans Cloudflare les secrets suivants avec des valeurs fortes :
- ADMIN_USERNAME
- ADMIN_PASSWORD
- SESSION_SECRET (valeur aléatoire d'au moins 32 caractères)
- GOOGLE_CLIENT_ID
- GOOGLE_CLIENT_SECRET
- GOOGLE_TOKEN_ENCRYPTION_KEY (valeur aléatoire longue)\n- RESEND_API_KEY (facultatif, pour les notifications e-mail)\n- ACTUSCOUT_EMAIL_FROM (adresse expéditrice vérifiée chez Resend, facultatif)\n- ACTUSCOUT_ADMIN_EMAIL (destinataire des candidatures ; par défaut actuscout@gmail.com)

Les notifications automatiques de candidature et d'acceptation ne partent que si RESEND_API_KEY\net ACTUSCOUT_EMAIL_FROM sont configurés avec un expéditeur validé par Resend.\n\nVariable non secrète requise pour les médias R2 :
R2_PUBLIC_BASE = https://pub-e89d0ce066dcb4b32a5acdfc6e80af4cb.r2.dev

Ne jamais inscrire les secrets dans GitHub, dans le code source ou dans un document public.
Ne jamais partager un jeton Cloudflare dans une conversation.
